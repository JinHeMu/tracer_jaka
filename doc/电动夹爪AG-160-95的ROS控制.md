

# 电动夹爪AG-160-95的ROS控制

<center> <b>2025.1.9 曹立</b> <center/>

## 1、赋予夹爪串口权限

```
# 列出当前主机所连接的串口，屏幕打印出 /dev/ttyUSB0 则说明夹爪的串口为ttyUSB0
ls /dev/ttyUSB*

# 赋予夹爪串口权限
sudo chmod a+rw /dev/ttyUSB0

```

## 2、开启夹爪驱动

```
cd /home/ras/caoli_ws

source ./devel/setup.bash
roslaunch dh_gripper_driver dh_gripper.launch

```

## 3、发布话题控制夹爪

```
cd /home/ras/caoli_ws

# 关闭夹爪
source ./devel/setup.bash
rostopic pub /gripper/ctrl dh_gripper_msgs/GripperCtrl "initialize: false
position: 0.0
force: 20.0
speed: 20.0" 

```
```
cd /home/ras/caoli_ws

# 打开夹爪
source ./devel/setup.bash
rostopic pub /gripper/ctrl dh_gripper_msgs/GripperCtrl "initialize: false
position: 1000.0
force: 20.0
speed: 20.0"

```

```
# 参数注释

position（位置控制）的范围是0-1000，（0关闭，1000打开）
force（力控制）的范围是20-100，
speed（速度控制）的范围是20-100，

```

## 4、调节滑动条对夹爪进行位置、力、速度控制

```
cd /home/ras/caoli_ws

source ./devel/setup.bash
rosrun control gripper_control_gui.py

```
